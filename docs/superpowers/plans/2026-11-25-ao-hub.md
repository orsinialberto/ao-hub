# ao-hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home di una sola schermata, in italiano e inglese, con un prato animato che gira su tre figure, ognuna porta di un sito.

**Architecture:** Build statico senza framework, come `ao-curriculum`: `src/pages.mjs` genera l'HTML in `dist/`. Titolo, bottoni e link sono HTML normale; la scena WebGL2 si aggiunge sopra. La logica (rotazione, semina, scia, pulizia bordi) sta in moduli puri testati con Node; il disegno WebGL si verifica a vista.

**Tech Stack:** HTML, CSS, moduli ES, WebGL2, Node ≥ 22 (`node --test`), GitHub Pages. Nessuna dipendenza del repository (`sharp` solo in locale con `npm i --no-save sharp`).

**Spec:** `docs/superpowers/specs/2026-11-25-ao-hub-design.md`

## Global Constraints

- Nessuna libreria a runtime, nessuna risorsa esterna (font nel sito), nessun tracciamento.
- Italiano su `/`, inglese su `/en/`; nessun reindirizzamento automatico; pagina 404 unica e bilingue.
- 90.000 fili su computer; 40.000 se `Math.min(innerWidth, innerHeight) < 700`.
- Link nella stessa scheda. Link e bottoni funzionano senza JavaScript e senza WebGL2.
- Ordine dei momenti: galleria (0), curriculum (1), blog (2). Ordine dei bottoni: Blog, Curriculum, Galleria.
- Non copiare né aprire il codice di `sangloo/stylized-grass`. Nessuna immagine o testo di theboringblog.ai.
- Foto personali, disegno di riferimento e PNG originali non entrano nel repository.
- La prova `~/dev/ao-hub-spike` si può rileggere; non si modifica.
- Percorsi **relativi** per risorse e link interni: l'indirizzo di prova è sotto una sottocartella.
- Commit locali a fine task. Creare il repository remoto, fare push e pubblicare richiede conferma di Alberto.

## Review Focus

1. Trascinamento interrotto (`pointercancel`, rilascio fuori finestra, cambio scheda): la scena si ferma comunque su un momento, mai bloccata a metà. Test nel Task 2 e 5.
2. Frecce premute molte volte di fila: arrivo su un momento, scritta e bottone coerenti con la figura. Test nel Task 2.
3. Contesto WebGL perso (telefono in background): compare l'immagine ferma, i link restano; al ripristino torna la scena. Verifica nel Task 5.
4. Una figura non si carica: prato, rotazione e link funzionano. Verifica nel Task 5.
5. Schermo largo 320 px o telefono in orizzontale (844×390): bottoni, scritta e selettore lingua non si sovrappongono e restano raggiungibili. Verifica nel Task 6.

### Task 2: Rotazione e scia (logica pura)

**Files:** Create `src/assets/js/rotation.js`, `src/assets/js/wake.js`, `test/rotation.test.mjs`, `test/wake.test.mjs`

**Interfaces:**
- `rotation.js`: `createRotation() -> state {pos:0, target:0, dragging:false, startStop:0}`; `dragStart(s)`; `dragBy(s, deltaPx, widthPx)` (tutta la larghezza = 1,5 scene; trascinare a destra diminuisce `pos`); `release(s, velocity /* scene al secondo */)`; `goTo(s, index)` (percorso più breve); `step(s, dir /* ±1 */)`; `tick(s, dt, reduced)`; `activeIndex(s) -> 0|1|2`; `figureVisibility(s) -> 0..1`.
- Regole: `release` sceglie `round(pos + clamp(velocity*0.25, -0.5, 0.5))`, al massimo a una scena da `startStop`. `tick`: `pos += (target-pos)*(1-exp(-7*dt))`, aggancio sotto 0,001; con `reduced`, `pos = target`; fermo se `dragging`. Visibilità: `d = |pos - round(pos)|`, `1 - smoothstep(0.15, 0.45, d)`.
- `wake.js`: `createWake({slots = 16, attack = 0.12, decay = 0.5, spacing = 0.35, radius = 0.8}) -> {pointer(point /* [x,z] | null */), update(dt), data() -> Float32Array(slots*4) /* x, z, raggio, forza */}`.

Causa degli scatti della prova, da non ripetere: punti creati a intervalli, subito a piena forza, il più vecchio eliminato di colpo; inoltre la somma delle spinte dipendeva dall'ordine. Regole nuove: il punto di testa insegue il puntatore (`1-exp(-18*dt)`); la forza sale e scende al massimo di `dt/attack` e `dt/decay` per aggiornamento; un posto si riusa o si sposta di colpo solo se la sua forza è ≤ 0,02; se nessuno è libero non si crea il punto.

- **Radura:** entro `CLEARING.radius` dal centro altezza ≤ `CLEARING.height`, niente ciuffi alti. È un cerchio perché la camera gira.
- **Scia:** `uPush[16]` da `wake.data()`; sommare le spinte e poi limitare la lunghezza (niente dipendenza dall'ordine); direzione `d / max(len, r*0.35)`, così non si ribalta al centro di un punto.

- **Dimensione:** isola più piccola in schermo. Partire da semi-larghezza `max(17, 8.5*aspect)` su schermi larghi; in verticale `7.2`. L'erba non deve entrare in titolo, riga e bottoni.
